# 📈 Smart Money Order Block Dashboard

A 100% free, lightweight, and interactive trading dashboard designed to help traders identify institutional **Order Blocks (OB)** and **Break of Structure (BOS)** to find high-probability Buy and Sell setups.

## 🚀 Features
- **Interactive Candlestick Chart:** Powered by TradingView Lightweight Charts.
- **Bullish Order Block Alert:** Highlights optimal discount zones for **BUY** entries.
- **Bearish Order Block Alert:** Highlights optimal premium zones for **SELL** entries.
- **Pure Frontend:** Zero backend required, completely hosted for free on GitHub Pages.

## 🛠️ How to Use
1. Open the live dashboard link.
2. Watch the market structure breakouts (**BOS** arrows).
3. Wait for the price to retest (mitigate) the highlighted green **Buy Zone** or red **Sell Zone**.
